# Cozy AI Studio

A calm web studio for turning a short product brief into a live HTML preview.

Write a brief, generate a self-contained HTML page, and inspect it in a sandboxed iframe. Revise in place without leaving the canvas.

## Run locally

```bash
npm run dev
```

Open [http://127.0.0.1:8080/studio](http://127.0.0.1:8080/studio) (or `/` for the landing page).

## What this repo is not

[canvas.h4ck3d.me](https://canvas.h4ck3d.me) is a different product (G0/G1/G2 pipeline, human-in-the-loop review, share links at `/a/:id`). That codebase is not this tree.
